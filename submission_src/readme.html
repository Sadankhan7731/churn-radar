How AI is used

  • Prediction: a logistic regression scores 100,000 synthetic subscribers from 40 signals (AUC 0.772).
  • Language: gpt-oss-120b writes the weekly briefing and answers questions from aggregate facts only; it chooses what-if scenarios, which the churn model computes.
  • Control: every figure is checked in code; qwen3.8-27b checks meaning; flagged sentences go back for repair; five planted errors test the checks.
  • Learning: on a live database, the model is checked against real cancellations, drift is measured, and a retrained challenger replaces it only after a person approves.

Running it locally (optional)

  • Python 3.9+: pip install -r requirements-dev.txt, put a Groq key in .env as GROQ_API_KEY=..., then python src/serve.py and open http://localhost:8000.
  • Live database demo: see connector/README.md (three commands: build the demo database, start the platform simulator, start the connector).

All data is synthetic; Lumen Play is a fictional company. Customer rows never leave the device or network; the AI receives aggregate figures only.
